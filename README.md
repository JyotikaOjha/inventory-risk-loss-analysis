# 📊 Inventory Risk & Loss Analysis Dashboard

**Electronics Warehouse Network | Sep 2024 – Sep 2026**

An Excel-based inventory analytics dashboard designed to identify inventory losses, monitor stockout risks, and provide management-friendly insights from 25,000+ transaction records.

## ⭐ Project Overview — STAR

### 1. Situation
Analyzed **25,000+ inventory transactions** across an electronics warehouse network covering **6 warehouses, 42 products, and 2 years of data**.

### 2. Task
Built a dashboard to monitor inventory movement, identify financial losses from **damage and returns**, and highlight stockout/reorder risks.

### 3. Action
Used **Microsoft Excel, Pivot Tables, Pivot Charts, formulas, helper columns, KPI cards, and slicers** to analyze:

- **₹23,333M** — Total Inventory Value Moved
- **₹230M** — Total Loss Value
- **0.99%** — Overall Loss Rate
- **6** — Stockout-Risk Transactions
- **8 days** — Average Lead Time

### 4. Result
The dashboard helped identify **high-loss products, inventory risk areas, and loss patterns**, converting 25,000+ raw transactions into a structured and management-friendly inventory analysis.
